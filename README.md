# 友愛接力卡號路線分析

線上地圖：<https://hippop3c.github.io/youbike-card-reward-route-map/>

內部分析工具，資料範圍為 2026-07-01 至 2026-09-13，沿用友愛接力口徑排除 2026-07-10、2026-07-11。

- 卡片以外觀卡號後五碼搭配匿名代碼顯示；完整卡號、帳號及訂單號不寫入網站資料。
- 可複選日期；選取多日後，累加該卡在所選日期的滿借、空還與獎勵騎乘次數。
- 點選卡片後，地圖顯示所有獎勵騎乘的起訖路線、方向與累積次數。
- 發布至獨立 GitHub Pages 專案；公開資料仍不包含完整卡號、帳號與訂單號。

資料建置：`python scripts/build_data.py`
